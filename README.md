# Project S.U.S.P.E.N.D.S : Solution for Unsure Scholars’ Problems about Evaluating the Need for the Declaration of Suspension 

## Description 
Project S.U.S.P.E.N.D.S is an all-in-one application that keeps scholars upto date with suspensions and can make predictions if they will be implemented.

## How to Run (After the Program is Coded)
First, download the .py file in this repository. Then, open the file in a Python-supported IDE. After pressing run, enter the asked inputs from the program. It will then output a verdict whether it will suspend or not, or a suspension has been upholded.

## Required Inputs
The program will ask for three inputs for three questions: <break> 
1. Has an advisory been posted about a current class suspension? <break>
2. Is there currently a hazard happening? <break>
3. Has a hazard happened that affected the flow of learning? <break>
